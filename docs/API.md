# Барахолка API

Базовый адрес: /api/v1/
Формат: JSON. Даты: ISO 8601. Деньги: строкой, например "12000.00".
Авторизация: заголовок Authorization: Bearer <токен>.

## Эндпоинты

| Метод | URL | Что делает | Кто может | Успех |
|-------|-----|------------|-----------|-------|
| GET | /listings/ | Лента объявлений, фильтры ?category= ?search= ?ordering= | Все | 200 |
| POST | /listings/ | Создать объявление | Вошедший | 201 |
| GET | /listings/{id}/ | Одно объявление | Все | 200 |
| PUT | /listings/{id}/ | Заменить объявление целиком | Автор объявления | 200 |
| PATCH | /listings/{id}/ | Изменить отдельные поля объявления | Автор объявления | 200 |
| DELETE | /listings/{id}/ | Удалить объявление | Автор объявления | 204 |
| POST | /listings/{id}/images/ | Добавить фото к объявлению | Автор объявления | 201 |
| DELETE | /listings/{id}/images/{image_id}/ | Удалить одно фото | Автор объявления | 204 |
| POST | /listings/{id}/favorite/ | Добавить объявление в избранное | Вошедший | 201 |
| DELETE | /listings/{id}/favorite/ | Убрать объявление из избранного | Вошедший | 204 |
| POST | /listings/{id}/reviews/ | Оставить отзыв о сделке по объявлению | Вошедший, кроме самого продавца | 201 |
| GET | /categories/ | Список категорий | Все | 200 |
| GET | /users/{id}/ | Публичный профиль пользователя | Все | 200 |
| GET | /users/{id}/reviews/ | Отзывы о продавце | Все | 200 |
| GET | /users/me/ | Мой профиль | Вошедший | 200 |
| PATCH | /users/me/ | Изменить мой профиль | Вошедший | 200 |
| GET | /users/me/favorites/ | Моё избранное | Вошедший | 200 |
| POST | /auth/register/ | Регистрация | Все | 201 |
| POST | /auth/login/ | Вход, в ответе токен | Все | 200 |

## Ошибки

| Код | Когда |
|-----|-------|
| 400 | Данные не прошли проверку, в теле ошибки по полям |
| 401 | Нет токена или он протух |
| 403 | Нет прав на это действие |
| 404 | Объект не найден |
| 405 | Метод не поддерживается по этому адресу |
